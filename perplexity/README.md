# Perplexity AI

Search prompt templates for [Perplexity AI](https://perplexity.ai) — useful for research tasks where you want cited, up-to-date answers.

## Templates

### Dependency research
```
Is [package-name] v[version] still actively maintained? Are there known security vulnerabilities? What is the recommended alternative if it is deprecated?
```

### Technology comparison
```
Compare [tech A] and [tech B] for [use case]. Focus on: maturity, community size, performance, ease of deployment, and known production issues. Cite recent sources.
```

### Error investigation
```
[paste error message]. This occurs in a [stack] application. What are the most common causes and how are they fixed? Show real examples if available.
```

### CVE lookup
```
What is CVE-[number]? Which versions are affected, what is the CVSS score, and what is the fix or mitigation?
```
