# GitHub Copilot

Configurations for [GitHub Copilot](https://github.com/features/copilot).

## `copilot-instructions.md`

GitHub Copilot reads `.github/copilot-instructions.md` to customise its suggestions for your repo. Copy `copilot-instructions.template.md` to `.github/copilot-instructions.md` in your project.

Reference: [GitHub Docs — Adding repository custom instructions](https://docs.github.com/en/copilot/customizing-copilot/adding-repository-custom-instructions-for-github-copilot)
